# AI Learning Frontend Prototype

This workspace contains a React-based frontend foundation for an AI personalized learning platform.

## What is implemented

- Basic UI layout with header, content sections, and footer
- Pages: Home, Login, Dashboard
- Client-side navigation using React Router
- Responsive layout for desktop and mobile
- Mock data for progress and recommendations

## Getting started

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

3. Open the local URL shown in terminal.
